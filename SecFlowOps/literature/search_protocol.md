# Literature Search Protocol

This file records the planned audit protocol for positioning SecFlowOps against prior work.

## Databases

- IEEE Xplore
- ACM Digital Library
- SpringerLink
- USENIX publications
- arXiv, only when paired with venue or artifact checks
- Tool documentation and official repositories for Trivy, Semgrep, OPA, and Gitleaks

## Query Families

- "DevSecOps automated remediation policy gate"
- "security scanning CI/CD empirical study"
- "software vulnerability remediation agents"
- "policy as code DevSecOps OPA"
- "SAST SCA IaC secret scanning pipeline"

## Inclusion Criteria

- Empirical DevSecOps or CI/CD security evaluation.
- Explicit pipeline, scanner, policy, or remediation component.
- Reproducible protocol, dataset, or artifact description.

## Exclusion Criteria

- Pure opinion papers without implemented evaluation.
- Vendor blog posts unless used only for tool behavior documentation.
- Papers without enough methodological detail to audit baselines or metrics.

## Audit Status

The bibliography audit is not complete. No novelty claim should be made until the selected references have been checked against primary sources.
