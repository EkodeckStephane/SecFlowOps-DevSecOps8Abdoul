\section{Formal Model and Calibrated Simulation}

SecFlowOps is modeled as a finding trajectory rather than as a scanner score. For a run $r$, let $F_0(r)$ be the initial multiset of normalized findings, $A(r)$ the bounded remediation operator, $F_1(r)=A(r,F_0(r))$ the residual multiset, and $P(F_1(r))\in\{\mathrm{allow},\mathrm{deny}\}$ the policy decision. When complete injected ground truth is available, $G(r)$ denotes the target findings introduced by construction. Detection recall and residual target count are then
\begin{equation}
\mathrm{recall}(r)=\frac{|\mathrm{match}(F_0(r),G(r))|}{|G(r)|},
\end{equation}
\begin{equation}
\mathrm{residualGT}(r)=|\mathrm{match}(F_1(r),G(r))|.
\end{equation}
These quantities are defined only when $G(r)$ is non-empty and complete. For external codebases without complete independent ground truth, SecFlowOps reports residual scanner findings and static adjudication, not natural-vulnerability recall.

The policy gate is a deterministic predicate over residual evidence. In the reported configuration,
\begin{equation}
P(F_1)=\mathrm{allow}
\end{equation}
only if residual critical findings equal zero, residual high findings are at most three, the maximum residual CVSS is at most 9.0, and no residual secret remains. This predicate is intentionally strict: a run may succeed experimentally while correctly denying delivery.

The calibrated simulation uses the 72 matched full-protocol C1/C5 run pairs as empirical input. For each pair, C1 supplies the unremediated finding set and C5 supplies the residual set observed after bounded remediation. Findings removed in C5 are treated as empirically removable; findings still present in C5 are treated as sticky under the implemented remediators. The simulation then varies only $q$, the probability that an empirically removable finding is removed before the policy gate. Thus $q=0$ reproduces policy-only behavior over unremediated findings, whereas $q=1$ reproduces the observed SecFlowOps residual state.

The simulation supports a bounded conclusion: under the observed finding distribution and the reported gate, partial remediation alone does not reproduce the full-policy outcome. The allow rate rises from 0.625 at $q=0$ to 0.722 at $q=0.75$, and reaches 1.0 only when all empirically removable findings are removed. The simulation is therefore a sensitivity analysis over the measured system, not a replacement for the ground-truth and scanner-based experiments.
