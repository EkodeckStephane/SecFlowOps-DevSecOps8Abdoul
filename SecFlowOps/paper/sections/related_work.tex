\section{Background and Related Work}

Secure-development frameworks such as NIST SSDF and OWASP SAMM emphasize vulnerability management, feedback loops, and measurable secure-development activities \cite{nistSSDF,owaspSAMM}. These frameworks motivate automation but do not prescribe a concrete experimental method for comparing scanner-only, remediation, and policy-gated DevSecOps pipelines.

SecFlowOps builds on existing tools rather than replacing them. Trivy provides vulnerability, secret, and misconfiguration scanning over filesystems and language ecosystems \cite{trivyDocs}. Semgrep supplies rule-driven SAST for source code \cite{semgrepDocs}. Gitleaks detects repository secrets \cite{gitleaksRepo}. npm audit supplies advisory-driven JavaScript dependency remediation \cite{npmAudit}. OPA provides policy-as-code enforcement through Rego and structured input decisions \cite{opaDocs}.

The artifact contribution is the integration and measurement layer: normalized finding records, explicit ground-truth linkage where available, deterministic remediation traces, post-remediation rescans, and policy decisions over residual findings. This places SecFlowOps closer to a reproducible benchmark harness than to a standalone AppSec product.
